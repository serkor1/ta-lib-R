# subchart

subchart

## Usage

``` r
subchart(data, title, ...)
```

## Arguments

- data:

  [data.frame](https://rdrr.io/r/base/data.frame.html)

- ...:

  arguments passed onto
  [plotly::plot_ly](https://rdrr.io/pkg/plotly/man/plot_ly.html)

## Details

A helper function for creating subcharts with prespecified xaxis and x
values
