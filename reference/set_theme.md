# Theme accessor

Access theme setters via `$`.

## Usage

``` r
set_theme()
```

## Value

Returns itself (so `set_theme()` is chainable with `$`).

## Details

Example: `set_theme$theme_tp_slapped()` or
`set_theme()$theme_tp_slapped()`.
