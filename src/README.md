# TA-Lib (core) wrappers

All wrappers are named `ta_FOO.c` and are generated by the templates in `/tools` and is generated as follows:

```sh
make gen-code
```

So all additions/deletions should be made using the templates. By default *all* templates returns a two-dimensional named array. The naming is based on the header files in [TA-Lib](https://github.com/TA-Lib/ta-lib/blob/main/include/ta_func.h) using some `awk` and `grep` magic. This has two implications:

1. The naming is decided upstream
2. The naming assumes that TA-Lib names columns *correctly*

The underlying BASH script behind generating the wrappers can be called as follows:

```sh
./generate_indicator_core.sh MACD > src/ta_MACD.c
```

This will create the `MACD`-indicator and store it in src as `ta_MACD.c`. Furthermore, [init.c] and [api.h] is *also* auto-generated and uses a greedy approach---if it returns a `SEXP` its exported to `R`, full stop.

All other files are written manually, and can be freely modified without having to consider templates.
